# Insertion sort
**Insertion sort** is a simple sorting algorithm that works by splitting collection into the sorted and unsorted part, and slowly building up the sorted part by inserting elements into their right place.

This algoritm is inefficient and is not used in practice because its worst-case and average case time complexities are high.

It is called like that, because elements are inserted where they should go.

## Complexity analysis
|            **Case**            |                     **Complexity**                     |
|:------------------------------:|:------------------------------------------------------:|
|    Worst-case<br>performance   | O(n<sup>2</sup>) comparisons<br>O(n<sup>2</sup>) swaps |
|     Average<br>performance     | O(n<sup>2</sup>) comparisons<br>O(n<sup>2</sup>) swaps |
|    Best-case<br>performance    |             O(n) comparisons<br>O(1) swaps             |
| Worst-case<br>space complexity |                          O(1)                          |

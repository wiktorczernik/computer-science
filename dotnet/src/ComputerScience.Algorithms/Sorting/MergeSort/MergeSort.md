# Merge sort
**Merge sort** is an efficient, stable sorting algorithm that follows divide and conquer paradigm. It works, by dividing unsorted collection into sub-collections, each containing one element and repeatedly merge sub-collections to produce new sorted sub-collections until there is only sub-collection remaining - this will be the sorted collection.

## Complexity analysis
|            **Case**            | **Complexity** |
|:------------------------------:|:--------------:|
|    Worst-case<br>performance   |   O(n log n)   |
|     Average<br>performance     |   O(n log n)   |
|    Best-case<br>performance    |   O(n log n)   |
| Worst-case<br>space complexity |      O(n)      |
